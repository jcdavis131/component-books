# Component Books — 12-Volume Compendium

Build any site from the suite of books of components. 214 plates across 12 books, enough to build any design dream.

Live:
- https://bhenre.com (primary)
- https://www.bhenre.com
- https://component-books-20gs9k06c-cams-projects-c5c4c5f6.vercel.app (Vercel URL)

## Books (12)

1. **foundations** — 18 plates (typography, palettes, spacing, radius, shadows, motion)
2. **buttons** — 25 plates
3. **forms** — 25 plates
4. **cards** — 20 plates
5. **navigation** — 20 plates (header, mega, sidebar, tabs, command palette, breadcrumbs, stepper, etc)
6. **data-display** — 20 plates (tables, stats, timeline, charts CSS-only)
7. **overlays** — 15 plates (modal, drawer, bottom sheet, popover, toast, lightbox, etc)
8. **marketing** — 20 plates (hero editorial/split/mockup, features, pricing, testimonials, footer, FAQ)
9. **layouts** — 15 plates (58/42 map/story → resizable workspace)
10. **media** — 12 plates
11. **feedback** — 12 plates
12. **commerce** — 12 plates

Each plate: id, name, style, description, real html + scoped css, props, tokens, useCases.

## App Views

- **Library** — bookshelf grid 12 covers
- **Reader** — rail + stage live/spec/code + inspector
- **Dictionary** — searchable index
- **Atelier** — token editor, stack reorder, picks per book, live assembled page, export CSS/Tailwind/JSON, copy HTML, shuffle

## Dev

```bash
npm install

```

Vercel native GitHub integration auto-deploys on push to `main`. Custom domain `bhenre.com` configured in Vercel dashboard.
